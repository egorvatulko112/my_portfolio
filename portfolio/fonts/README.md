# Шрифты из PDF

Это новые подмножества шрифтов, восстановленные из видимых кривых
предоставленного макета. Полные оригинальные гарнитуры в PDF не встроены:
служебный `FigmaGlyphs` содержит только метрики и пустые глифы.

| Файл | Где используется |
| --- | --- |
| `sans-regular.woff` / `.ttf` | Навигация, обычный текст, подписи и BACKEND |
| `sans-semibold.woff` / `.ttf` | Заголовки, основные кнопки и SEE MORE |
| `mono-regular.woff` / `.ttf` | Описание backend и список технологий |
| `contact-regular.woff` / `.ttf` | Почта и номер телефона |

У всех символов текста макета есть восстановленные глифы. Кириллицы и
полных алфавитов здесь нет; при добавлении нового текста работает системный
шрифт из CSS. Поэтому имена исходных шрифтов не заявляются как достоверные.
Детали и перечень символов находятся в `../source/pdf-extraction.json`.
