# EGOR Portfolio

Адаптивный фронтэнд, перенесенный из предоставленного PDF-макета Figma.
Обычные HTML, CSS и JavaScript: без npm, сборщика, CDN и зависимостей.

## Запуск

Открой `source/index.html` в браузере. Изображения и шрифты лежат рядом и
загружаются локально; для запуска не требуется установка библиотек.

Для разработки удобнее открыть терминал в папке `portfolio` и выполнить:

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000/source/`.

## Структура

| Папка | Содержимое |
| --- | --- |
| `source` | `index.html`, `styles.css`, `site.js`, `content.js` и отчет об извлечении |
| `media` | Исходное изображение запуска, растровые свечения, большой логотип в SVG и PNG |
| `fonts` | Четыре восстановленных начертания в WOFF и TTF |
| `icons` | Логотип EGOR, SVG-иконки Instagram, WhatsApp, LinkedIn и PNG-иконка backend |

## Что перенесено

- Текст, размеры и расположение блоков из PDF. Английские формулировки и
  опечатки сохранены, чтобы не менять содержимое макета.
- Растровые изображения в их исходном разрешении с прозрачностью PDF.
- Векторные контуры логотипа и социальных иконок.
- Реальные контуры букв, восстановленные в новые веб-шрифты. Исходный PDF
  содержит пустой служебный Type 3 `FigmaGlyphs`, а видимые буквы нарисованы
  кривыми. Названия оригинальных гарнитур и полные исходные шрифты в нем
  отсутствуют. Восстановленные файлы содержат только символы макета;
  новые отсутствующие символы браузер возьмет из системного запасного шрифта.
- Кернинг между буквами, восстановленный из координат PDF. Размеры, трекинг,
  интервалы и цвета находятся в `styles.css`.

Три карточки проектов в исходном макете пустые. Они оставлены пустыми, реальные
проекты не выдуманы. Кнопка SEE MORE открывает панель проектов.

## Как заполнить портфолио

Измени `source/content.js`: почту, телефон, ссылки Instagram / LinkedIn и
массив `projects`. Пути к изображениям задавай относительно `source/index.html`,
например `../media/my-project.png`. Первые три проекта появятся на странице,
все остальные — в панели SEE MORE. Не забудь самостоятельно проверить,
что контакты из макета твои и действуют.

Профили Instagram и LinkedIn не указаны в PDF. Пока ты не добавишь их ссылки,
эти иконки открывают окно контактов. WhatsApp использует номер из макета.
Почта и телефон уже открывают соответствующие приложения.

LOGIN открывает форму входа с полями и проверкой заполнения. Авторизация
не подключена: форма показывает сообщение о недоступности входа и не
отправляет / не сохраняет введенные данные. Для настоящего входа обработчик
формы в `source/site.js` нужно связать с твоим бэкендом, например на Axum.

## Адаптивность и доступность

На ширине 1024px композиция соответствует исходному макету. На больших
экранах размеры увеличиваются до установленного предела. На телефонах
навигация становится раскрывающейся, проекты идут одной колонкой,
контактные блоки располагаются друг под другом.

Текст остается выделяемым; используются семантические заголовки, якоря,
подписи для кнопок и поля формы. Модальные окна закрываются по Escape,
кнопке и клику вне окна. После закрытия фокус возвращается к исходной кнопке.
Учтено `prefers-reduced-motion`.

## Проверка

Проверены синтаксис JavaScript, локальные ссылки на ассеты, якоря, структура
HTML/SVG, загрузка восстановленных TTF/WOFF и наличие символов исходного текста.
Контуры восстановленных шрифтов проверены отдельным растровым рендером.
В этой среде не было доступного средства браузерной проверки: полный HTML
не проверен визуально в браузере. Перед публикацией проверь страницу на своем
экране и телефоне.
